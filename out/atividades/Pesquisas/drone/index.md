## Sobre a pesquisa

Esta pesquisa desenvolve um sistema de controle dinâmico para um dispositivo quadrirotor.

O estudo aborda a modelagem do drone, a leitura de sensores, o processamento dos dados e estratégias de controle para tornar o voo mais estável e preciso. O projeto também investiga como os parâmetros do sistema influenciam a resposta dinâmica do dispositivo.
